# 家庭成长跟踪用户指南

家庭成长跟踪面向家长和孩子，记录德育、智育、体育、美育、劳育五个维度的
成长任务和完成情况。家长负责家庭、孩子、任务和反馈管理，孩子通过独立入口
查看并完成自己的任务。

## 使用入口

| 角色 | 入口 | 登录方式 |
| --- | --- | --- |
| 家长 | “注册家长账号”或“家长登录” | 用户名和密码 |
| 孩子 | 家长打开或复制的专属入口 | 4至6位PIN；Family ID＋Child ID仅为手工备用方式 |

首次使用时，家长需要先完成注册、创建家庭、添加孩子并设置PIN，再打开或复制孩子专属入口。
入口不包含PIN，也不代替认证。Family ID、Child ID仍可在“孩子”页面查看，用于手工备用登录。
不同孩子可在独立标签页分别登录；家长会话仍在同浏览器共享，共享设备交给孩子前应退出家长账号。

## 当前功能边界

- 家长主导航包括“今日、任务、记录、知识与能力点、错题、学习包、周报、提醒、星星与奖励、孩子、家庭成员”；“重复计划”从任务页进入。“学习包”入口存在不代表当前关闭的AI2可用。
- 孩子端导航为“今天、错题、成就、我的”。
- 孩子只能查看自己的数据，不能创建任务、修改奖励或执行兑换。
- 错题用于智育复盘；德育、体育、美育和劳育活动通过任务与成长记录跟踪。
- 当前版本不包含教师、班级、成绩、邮箱找回密码或原生移动应用。
- AI1家长候选讲解、AI2发布与订正、AI3少量变式题已有工程实现，但上述已核对记录中的AI1/2/3均关闭，不能把入口或合成测试当作真实模型已可用。
- K12课程映射、内置画板/Apple Pencil笔迹处理、OCR及自动判题未提供。纸上或外部工具作答后上传图片不等于内置手写能力。
- 普通任务提交与家长审核、人工求助回应不依赖AI；AI学习包的发布/订正需按其单独启用条件，不因有图片上传功能自动开放。
- [完整AI平台草案](../architecture/family-ai-learning-platform-design.md)仍包含未开发或后置内容；当前最小实现与限制以SRS及其关联设计/证据为准。

## 隐私提示

- Family ID、Child ID 和孩子 PIN 只在家庭成员之间私下传递，不要发布到群聊、
  公共文档或截图中。
- 家长重设 PIN 后，孩子需要使用新 PIN 重新登录。
- 任务附件和错题附件属于私有内容，应从对应页面的预览或下载操作打开；不要转发短时访问地址。
- 不要在用户指南、反馈或截图中粘贴账号密码、PIN 或服务配置。

文档内容以当前 Web 界面为准。部署地址由实际运行环境决定，因此指南不固定
具体域名。
