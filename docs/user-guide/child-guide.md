# 孩子操作指南

孩子端只显示当前孩子自己的任务、成长反思、待复习错题、星星、奖励和个人资料。请先向
家长取得 Family ID、Child ID 和 PIN。

## 1. 使用 PIN 登录

1. 打开“孩子登录”。
2. 输入家长提供的 Family ID。
3. 输入自己的 Child ID。
4. 输入 4 至 6 位 PIN。
5. 选择“进入我的成长空间”。

出现“家庭、孩子或 PIN 不正确”时，先检查输入内容，再请家长到“孩子”页面
核对标识或重新设置 PIN。出现“尝试次数过多，请稍后再试”时，等待一段时间后
再登录。

PIN 只告诉家长或负责照顾你的家庭成员，不要发到群聊或公共截图中。

## 2. 孩子端导航

| 导航 | 可以做什么 |
| --- | --- |
| 今天 | 查看今天的任务和提醒，进入“本周反思” |
| 错题 | 复习还没有掌握的错题 |
| 成就 | 查看星星、家庭奖励和已完成的成长 |
| 我的 | 查看个人资料和退出孩子端 |

## 3. 查看今日任务

打开“今天”，在“今天的任务”中查看家长安排的内容。“待完成”“等待家长确认”和
已经确认的任务都可打开详情，查看当前作品版本、图片和家长反馈。

常见状态：

- “待完成”：现在可以打开并提交完成情况。
- “等待家长确认”：已经提交，等家长检查。
- “已获得星星”：家长已经确认完成。
- “已取消”或“已归档”：任务不再需要提交。

“今日提醒”可能提示任务到期、错题复习或其他家庭提醒。如果某一类提醒暂时无法
加载，其余提醒仍然有效，可以稍后重新加载。

## 4. 提交任务完成情况

1. 在“今天”打开一个“待完成”任务。
2. 填写实际用时和实际完成数量。
3. 选择完成难度：轻松、刚刚好或有挑战。
4. 完成过程中需要家长协助时，勾选“完成时需要帮助”（这是本次自评，不是独立求助消息）。
5. 在“我的一句话”中写下感受或问题。
6. 按需使用“添加完成图片”选择作品，最多 10 张 JPEG、PNG 或 WebP，每张不超过 10 MiB；也可以不加图片。
7. 选择“提交完成情况”。

成功后显示作品版本与“等待家长确认”。确认前可选择“修改本次完成”；家长确认后只读，但仍可看作品和反馈。
图片通过眼睛按钮授权查看，放大链接打开完整图片。HEIC 和 PDF 不能作为完成作品；iPad 的 HEIC 照片请先明确导出为 JPEG，不能只改文件后缀。
多张上传时，失败项会单独提示，已成功项保留，不要重新选择全部图片。

提交结果未确认时，选择“重试本次提交”，不要另建一次提交；刷新后仍会保留本次重试入口。
退出会清理当前设备上的提交暂存；同一孩子重登后，可在“今天”的“待恢复提交”选择“检查待恢复提交”，
打开对应任务，再选择“继续上次提交”。该入口也可找到不是今天的待恢复任务；另一位提交者的记录不能代为恢复。
尚未上传或尚未发送到服务端的草稿不保证重登恢复。

减号按钮只是从本次列表移除图片，提交修改才变更作品引用，不删除原图片资产。
垃圾桶按钮是“隐私删除”，必须另行确认；删除后不能再读取图片，但不改变任务和星星。
离开页面或取消选择不会自动删除完成图片，当前新孤儿自动回收未启用。

以上作品流程仅在新协议已启用且获准的环境使用。本轮仅完成合成环境工程验证，不代表家庭环境已部署，真实 iPad 仍待实测。

## 5. 复习错题

打开“错题”可以看到还没有掌握的智育错题。孩子端只显示复习需要的信息和自己
填写的解释，不显示家长的私有备注。

要记录新错题，选择“记录新错题”，填写学科、错误原因和可选说明。可以为题目
和自己的答案分别添加图片或 PDF，每组最多 10 个；每个文件不超过 10 MiB，PDF
最多 50 页。尚未提交时取消会清理本次上传草稿；提交后结果不确定时附件会保留，先核对原记录，不重复创建。

1. 找到要复习的错题。
2. 按需预览图片或下载 PDF，也可以增删自己的题目和答案附件。
3. 在“我的解释”中写下自己的理解。
4. 还不确定时选择“我还不会”。
5. 已经理解并能正确完成时选择“我已经会了”。

选择“我已经会了”后，这道题会从待复习列表中移出。如果仍有疑问，应选择
“我还不会”并请家长帮助。

### 订正与来源回看（T6 限定合成工程已验收）

家长创建订正任务后，仍从任务页完成、提交作品并查看家长反馈。详情中的“查看来源错题”可以打开对应错题，
错题中的“查看来源任务”可以回看原任务。只能查看当前账号有权限的记录；来源不可用时不显示原来的私有内容。
完成或获家长确认不会替你选择“我已经会了”，复习后再作真实判断。工程验收不代表真实家庭已部署，真机保持 DEVICE_PENDING。

## 6. 查看成就和奖励

打开“成就”可以查看：

- “我的星星”
- “家庭奖励”
- “星星记录”
- “已经完成的成长”

达到奖励所需星星后，页面会提示“可以请家长兑换”。孩子端不能直接兑换或创建
奖励，请与家长确认后由家长在“星星与奖励”中操作。

## 7. 我的资料、退出和会话过期

打开“我的”可以查看姓名、年级、兴趣、需要加强的学科、喜欢的运动、艺术兴趣、
劳动习惯和品德目标。当前孩子端只供查看，不能直接修改资料。

在共享设备上使用完毕后，选择“退出孩子端”。如果会话过期，系统会返回登录
流程并提示重新登录；如果家长刚刚重设 PIN，必须使用新 PIN。

遇到暂时无法加载时，先选择页面上的重新加载操作。仍然失败时，告诉家长当前
页面和提示内容，但不要把 PIN 放进截图。

## 8. 本周反思（T7 工程候选，尚待验收）

1. 从“今天”进入“本周反思”，在“反思所在周”选择要回看的日期；页面按家庭时区所在自然周显示记录。
2. 优先在已有记录上选择“修改反思”，写一句收获或下一次想改进的事，选择“保存反思”。一年级一句话即可，也可请家长代录。
3. 没有合适记录时选择“新增反思”，填写记录日期、成长维度、记录内容和反思。反思最多 500 字，不需要填写学习时长。
4. 保存后可刷新页面回看。修改已有反思时允许主动清空；不更改原记录正文、学习时长或家长备注。

“保存结果尚未确定”不等于失败。当前编辑会保留输入并禁止再次提交；选择“重读全部记录并核对”，
与已保存记录逐条核对后，明确选择“已核对，结束上次编辑”。没有找到记录也不能证明上次保存失败。
读取失败时继续保留保护，请稍后重新读取，不要反复新建。结束核对后重新选择记录编辑，不自动重放原修改。

关闭编辑、刷新或退出重登不能当作解除未知写入的办法。同一孩子重登后仍需核对；退出会清除私有界面和内存草稿，
不会替你保留未保存正文。换成兄弟姐妹账号不会显示你的反思或保护提示。
反思不会额外发星，也不会替你把错题标为掌握。当前候选仅作合成验证，真实 iPad 保持 DEVICE_PENDING。
