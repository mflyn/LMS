## 当前可运行闭环

正式 AI1 人工修订批准、AI2 订正审核后，task/mistake 两类来源分别进入 AI3。
每类均完成两题手工候选、三题合成生成后人工修订、全文/孩子预览、发布、孩子图片提交、
家长退回、孩子重新提交、家长按所见版本通过及孩子回看。作答覆盖1张和10张图片。
task 关联本地数学知识点并应用掌握效果；mistake 无知识点时仅应用错题复习效果，不伪报掌握。
最终通过快照检查实际目标状态及 revision、对应审核的回执/事件/时间，以及原审核重放后六表不变。

提交结果故障使用真实服务端201/SUCCEEDED，然后仅向页面交付缺少命令结果的200响应。
这是“提交成功但结果不可验证”，不是网络断链。刷新保留原命令，实际退出清理暂存，重新登录后
发现原命令并显式恢复；点击之前零recover、点击后一次原ID请求，全程仅一次submit且Attempt不变。
真正提交后销毁HTTP连接的故障在独立正式HTTP套件中验证，不能与上述浏览器故障混称。
