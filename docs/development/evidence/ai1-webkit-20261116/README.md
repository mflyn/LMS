## 最小修订与保护

- 登录后从家长导航进入任务/错题，已有周期从“讲解记录 → 查看讲解”进入，检查目标URL和文档身份；不伪造导航链接或等待网络空闲。
- 保留真正的页面刷新、新标签直达、真实JWT过期、共管重登及原命令恢复路径；没有声称任意硬文档替换或原生WebKit限制已修复。
- 对取消、明确注入失败、提交后丢响应采用有限的引擎精确契约，绑定URL、method及无HTTP响应。
- WebKit的Inspector注入失败仅产生精确info事件，Chromium产生精确error；两者分别检查，新增warning/error仍失败，不用任意错误通配。
- 保留零pageerror、所有原业务状态、私有内容清理、UUID/正文深相等、写入/远端次数、版本/费用/审计不变断言。
- 在途和正常完成导航各覆盖任务/错题；非法请求身份、非取消错误、非预期console均必须拒绝。持有响应在异常路径释放，并等待路由收尾。
