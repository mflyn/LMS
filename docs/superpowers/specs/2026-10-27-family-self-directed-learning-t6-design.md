# T6 人工错题、订正与复习连接

日期：2026-10-27。状态：设计、自查、独立评审及限定合成工程验收获用户批准；总门禁 CLOSED，仅限 ENGINEERING_SYNTHETIC_ONLY。
依据：MVP 计划 T6、API §14.5、用户 T6 完整执行目标。仅合成验证，不授权 Git 写入或部署。

## 1. 范围与选择

复用 FamilyMistake、GrowthTask、完成审核、媒体和 reviewReminderDate。
任务作品 -> 错题 -> 订正任务 -> 孩子完成 -> 家长审核 -> 到期人工复习 -> 来源回看。
选择两个独立创建动作和可选单向来源；不采用跨服务事务向导、自动媒体复制或关系图谱。
任务确认不自动修改错题的 corrected/reviewed/mastered；原任务状态、奖励和已确认证据不变。

## 2. 数据和权限

- FamilyMistake 增加可选 sourceTaskId；GrowthTask 增加可选 sourceTaskId/sourceMistakeId，二者互斥。
- 来源仅在创建时设定，PATCH 禁止修改（实现选择：避免改写来源及扩张编辑语义）；历史缺省不回填。
- ID 使用严格 24 位十六进制输入，规范化小写；null、空串和对象不作为有效来源。
- 家长可沿已授权任务/错题创建；孩子保留原有错题创建与字段权限，可记录本人任务来源，不能创建任务。
- taskType 沿现有字段填写“错题订正”，不新建任务类型系统。来源任务允许所有正常可读状态，
  cancelled/archived 本身不是跨 scope 或删除，不通过关联重新打开它。
- 同服务来源查询也限定 _id/familyId/childId。跨服务只通过内部最小读取，不导入对方模型查库。

## 3. 内部读取与错误

- homework: GET /api/internal/learning-sources/tasks/:sourceId?familyId=...&childId=...
- analytics: GET /api/internal/learning-sources/mistakes/:sourceId?familyId=...&childId=...
- 复用 INTERNAL_SERVICE_TOKEN 和现有内部凭据鉴权风格；无有效配置时拒绝内部访问。
  使用 HOMEWORK_SERVICE_URL / ANALYTICS_SERVICE_URL，缺配置的关联创建失败关闭，旧无来源功能继续可用。
- 响应仅 success/data/source，source 为 {id,familyId,childId,subject,title}，不包含媒体、正文或下级来源。
  title 是任务标题或错题知识点/学科，subject 缺省规范化为空串（合法旧任务不能因此被拒绝）；
  客户端严格验证 scope、ID 和字符串类型，禁止自动重定向。
- 权威服务只进行一次限定 scope 的读取；无记录统一 404 RESOURCE_NOT_FOUND，不越权补查真实归属。
- 上层先验证当前用户能操作目标孩子，再核验来源；不存在/跨孩子/跨家庭统一相同 404 错误正文。
- 来源超时、连接失败、无效凭据、异常/不匹配响应统一脱敏 503 SOURCE_SERVICE_UNAVAILABLE，
  不返回上游正文或请求配置，不伪装成不存在，不降级保存未验证来源。不自动重试 POST。
- 内部审计仅记来源类型、结果分类；不得记录 Token、标题、正文或其他家庭数据。

## 4. 创建与详情

- 普通创建和带媒体创建均在开始持久化/媒体编排前完成来源校验。后续失败遵守现有事务和媒体编排，
  不在来源校验失败时产生新业务对象或媒体绑定；不扩大已有媒体恢复协议。
- 校验与保存不是分布式原子快照：来源之后不可读不撤销已保存对象，详情实时查来源并降级不可用。
- 创建/列表/变更响应保留可选来源 ID；仅单对象详情附 sourceAvailable 与最小 source 投影，
  无来源的历史对象不需远程读取，不增加列表 N+1 或递归加载。
- 已授权详情的来源不存在时 sourceAvailable=false、source=null；远程故障返回 503，界面清除旧
  来源投影并提示重试，不谎称永久删除。无来源时不显示来源入口。
- 所有 source 链接只携带不含正文的 ID，进入目标页面后重新鉴权，不信任 URL 或路由预填数据。

## 5. 页面与失败

- 家长任务详情提供“记录错题”“创建订正任务”；错题详情提供“创建订正任务”和来源回看。
- 在现有页面内用路由参数表达打开对象/创建来源；读取当前身份和孩子下的权威详情后才预填学科。
  不根据 URL 强制切换孩子；异 scope 返回拒绝并清空预填/私有界面，旧响应不得恢复。
- 两步分别明确保存。取消第二步不删除第一步；第二步失败保留本身份表单，并提供查看已保存对象入口。
- 明确创建响应未知不等于失败：提示先检查列表，不自动再次创建；沿既有明确 resourceId 的媒体
  pending 恢复入口接续，不发明全局幂等 UUID 或通用恢复机制。
- 孩子创建无 resourceId 时提供显式“重新读取错题列表”，等待当前身份下的真实 GET 完成；
  网络/5xx/损坏响应保留未知保护和重试入口，403 清空私有视图。列表只发现新增行，不能重置其他行草稿或未知 PATCH 锁。
  提交前在 sessionStorage 以 familyId/childId 为范围保存单一未知位，不保存题目、附件、命令或凭据；
  关闭表单、刷新及同标签退出/切回原孩子不丢失保护，其他孩子不继承该标记或私有内容，旧响应不能解除新会话的锁。
  存储不可用时不提交；明确写前拒绝或已知成功可清除标记。无 ID 结果未知不能自动再次 POST。
  列表成功后仍需用户明确“已核对列表，结束本次记录”；过滤/分页列表未出现不证明保存失败。
  本标记不是跨设备恢复或创建幂等协议，关闭整个标签、清除浏览器存储后的持久恢复不在本次承诺内。
- 媒体 pending/传输未知后用既有 retainSubmitted 接管已提交草稿，关闭、卸载或切换身份不能删除
  可能已绑定的媒体。恢复原对象不以来源再次可读为前提；来源故障和媒体 pending 同时发生须测试。
- 明确 SOURCE_SERVICE_UNAVAILABLE 在创建时发生于写入前，可保留表单人工重试，不能当成所有
  5xx 通用未知结果。来源不存在、来源服务故障、媒体 pending/传输未知三类动作必须区分。
- 完成作品必须重新按 mistake_question/mistake_answer 上传；复用现有图片/PDF/多附件校验与隐私保护。
- 订正任务的完成、审核、回看沿原页面。孩子错题页面保留原人工操作，增加安全来源回看；
  提醒按当前授权身份定位对应错题。复习日期和无日期提醒规则不变，不增加定时任务。
- 本次错题页面按会话身份/revision 隔离；家长端再绑定家庭、孩子和 scope version。不能假定同角色
  切换账号会卸载路由。当前拒绝清空全部私有状态，所有异步回调校验身份与代次，不扩为全站重构。
- 来源展示的暂时隐藏独立于行编辑数据；读取其他错题不得清空未保存解释、附件或解除原行未知写入锁。
  来源 503 保留草稿和锁，只有原错题权威重读成功才替换该行；当前 403 仍清理全部私有状态。

## 6. 验证与回退

复用 common/analytics/homework 单测、前端组件、T2 正式 HTTP/浏览器夹具与现有发布门禁。
永久反例覆盖：三种来源成功、互斥/非法输入、scope 统一404、凭据拒绝、超时/异常响应、来源消失、
媒体目的拒绝与来源校验/已确定回滚失败零新增（pending/未知不适用）、旧无来源兼容、两步独立保存、未知结果不自动POST、身份切换/迟到响应、
版本审核和原任务/奖励不变、可控日期提醒/人工复习。正式集成使用 enabled，不以 mock 替代最终闭环。
T6 的关键新测试须纳入既有实际 Gate；不将尚未接入的测试写成 CI 已覆盖。

不触碰真实数据库/服务器/凭据；不新建索引除非实际查询需要并已验证。真实回退与恢复属于 T8。
