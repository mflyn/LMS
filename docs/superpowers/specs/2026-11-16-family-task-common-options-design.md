## 1. 目标与取舍

家长创建或修改普通任务、重复计划时，能选择常用任务类型、具体项目和学科，也能填写已有选项之外的内容。减少手输，不改变任务、奖励或命令协议。

采用用户已选择的原生 select 加“其他（手工输入）”模式；选择其他才显示关联文本框。普通任务和重复计划使用相同选项与交互规则，但不强行统一原有必填性、字段可见性、请求拼装和恢复状态机。

备选：datalist 更接近原自由文本，但“其他”入口和移动端候选交互不够明确；可搜索自定义组合框需要额外键盘/焦点治理，本次不采用。无需新控件依赖。

范围仅限家长 `/app/tasks` 和 `/app/recurring-plans` 的创建/编辑表单。成长维度、单位、日期、任务标题、说明、数值输入保持原交互；不改错题、知识点、日志等其他表单，不新增分类管理、远端字典、家庭自定义词库、自动学习或本地持久化词库。

## 4. 值与交互规则

1. select 的选项身份与业务值分离，使用不混淆的 UI token/索引；“其他”是 UI 模式而非提交的哨兵值。历史字面值“其他”、`other` 或与 UI token 相同的自定义字符串仍按普通文本显示并可原样提交。
2. 精确匹配常用提交值时选中该项；其余非空旧值显示“其他”及原文。不按大小写、别名或翻译替换旧值。旧 `math`、`Math` 显示为其他原文，保持现有数学讲解入口识别；新选数学提交 `数学`。不将旧中文“锻炼”强制改为 exercise。
3. 空字段显示“请选择”占位；可选字段允许回到空占位。仅对本次新建/编辑请求适用的字段执行表单校验：选择“其他”后，文本 trim 为空时显示字段级错误，零保存请求、零新命令标记；可选字段若要留空必须明确回到空占位，而非提交未完成的“其他”。必填字段空占位同样拒绝。保存处理函数也必须执行这项检查，不能只依赖 HTML required。普通任务的学科仅在 `dimension === 'academic'` 时适用；隐藏的非智育学科不运行 required 或其他空白校验，不阻止保存，也不显示阻断性学科错误。不能用删除学科草稿来绕过校验。重复计划学科始终适用且可选，不因非智育而跳过“其他未填写”的检查。
4. 普通重渲染、非破坏性列表刷新不重置未提交输入；不得用自动同步 effect 在选项变化时覆盖用户值。“其他→常用”明确切换时只采用所选值，清掉该字段旧自定义草稿；再次选其他为空，避免隐藏旧文本意外提交。这是显式编辑，不适用于身份切换或已冻结命令。
5. 切换成长维度只更新项目建议，不修改当前 area/taskType/subject。原项目不在新建议表时转为其他显示原值，不选新组第一项；同一次编辑中“其他但未输入”的模式也保留。普通任务隐藏非智育学科时，保留同一身份、同一编辑会话内的选择模式和原始文本（包括空串、空白及旧别名），不只是保留解析后的业务值；切回智育恢复原模式与原文，重新按适用字段校验，不能自动选第一项。普通重渲染/列表刷新不清草稿；关闭表单、开启另一条任务编辑或身份失效后不得复活旧草稿。实际新建/编辑请求仍遵守非智育不发送 subject 的规则。重复计划学科仍可见且可选，不扩大联动逻辑。
6. 编辑重复计划继续以 pendingRevision 优先、否则 currentRevision 初始化。下拉控件不更改明日起生效规则，也不覆盖今日任务。普通任务的来源预填“错题订正”、检查清单、附件与版本字段保持不变。
7. 新控件受原 fieldset disabled/busy/recovery/pending/权限状态统一约束，不能通过其他输入框绕过。字段名和其他输入框均有唯一可访问 label（例如“具体项目”“其他具体项目”），错误关联对应字段。采用原生 select，触控高度至少 44px，在 360px 与平板宽度检查换行和遮挡；浏览器模拟不冒充 iPad 真机验收。

实现建议：一个窄的共用选项输入组件和一个静态选项模块，父页面继续持有业务字段。编辑会话身份变化时重建组件；UI 模式只在当前表单内存在，不写 localStorage/sessionStorage。不得把整个表单重构成新框架。

## 5. API、原命令与身份边界

不新增接口、请求字段、数据库字段、schema 版本或迁移。普通任务仍发送既有 `taskType/area/subject`；重复计划仍使用 `template.taskType/template.area/template.subject`。显示名、选项索引、otherMode/customText 等 UI 元数据不得进入请求正文或摘要。正常新命令在字段校验成功后，使用当前表单的实际业务值进入既有规范化；不新增大小写折叠、同义词归一或字段默认。

普通任务新建/编辑正文中，非智育时必须完全省略 `subject` 属性，不能发送隐藏草稿、空串或 null 代替；这沿用现有请求拼装，不意味着删除数据库中已有 subject。切回智育再提交时使用恢复的有效草稿；重复计划不套用该省略规则。此规则仅作用于新的表单提交，已保存的恢复 payload/原命令不得按当前维度删改字段或重算摘要。

例：锻炼+跳绳提交 `taskType: "exercise", area: "跳绳"`；其他类型“亲子活动”与项目“社区观察”提交相应原文字段（沿用已有 trim），不是提交 `other`。

沿用[普通任务 API](../../api/family-learning-tracker-api.md)及[重复计划 API](../../api/family-recurring-tasks-api.md)。本设计的前端选项不是 API 新白名单；不能据此将旧合法值拒绝或迁移。

恢复边界：

- 重复计划已保存的原命令正文、UUID、requestDigest、expectedVersion 不因打开下拉、刷新、选项表调整或重登而改变；查询/重试/安全终止继续走原命令模块。不得用当前表单或最新规则重建旧正文，亦不得对旧命令再跑新增 UI 必填检查。null/省略/空字符串的原命令区别继续保留。
- 未决命令存在时不新建管理命令，不通过切换其他选项清掉标记。关闭/未就绪/刷新在途时仍阻止新操作；摘要完成、持久化前的最新可写及身份校验不移动、不削弱，busy 收尾仍有效。
- 普通任务没有与重复计划完全相同的 UUID 恢复协议；只保留既有材料/编辑恢复 payload 和版本流程，不为控件改动引入通用恢复框架。不从恢复 payload 抽字段回填成一条新保存意图。
- 当前身份遭遇 401/403、退出、换家长或换孩子时，新增自定义输入及隐藏草稿随原私有表单清理，包括业务文本、其他输入文本、选择模式及字段错误；不能只清可见输入。即使随后回到同一账号/孩子，也不恢复已失效编辑会话的草稿。迟到读取或写入不能恢复它们，不能删另一身份的原命令；同 actor 重登后的既有原命令恢复仍按原协议执行，与未提交草稿清理分开。普通任务沿用 editorGeneration/mutationGuard，重复计划沿用 session/epoch/scope 和 marker 规则。
- 常用词是静态、非个人数据；不从其他孩子/家庭历史记录收集建议。后端实时家庭/孩子权限与拒绝顺序保持原样。

旧字段为空时的普通 UI 提示不表示旧命令失效；已有命令恢复不经过本批新表单路径。回滚只撤回新控件和选项层，不回写历史数据、不删除命令或证据。
